## What I actually did

**Implementing and benchmarking the deep learning models.** The **web scraping was done by Réda
Ouzzane** — I don't claim it.

This was our first real dive into the field: working through François Chollet's *Deep Learning
with Python*, we set out to throw as many existing architectures and techniques as we could at
the dataset we had collected.

## The project

A hands-on introduction to deep learning applied to football data gathered by web scraping. The
goal was never to beat a state of the art, but to methodically test a wide range of
architectures and techniques on a real, noisy dataset.
